# DataPilot AI API Contracts

## Status

The endpoint names and purposes below are approved by the project proposal. Request bodies, response schemas, validation limits, status values, and error formats are intentionally provisional and will be finalized incrementally as the corresponding backend task is implemented and reviewed.

Rahman consumes the reviewed contract from the frontend. Akbar owns backend contract updates. Neither member should silently invent incompatible fields.

## Approved endpoints

| Method | Endpoint | Purpose | Schema status |
| --- | --- | --- | --- |
| `GET` | `/api/health/` | Check backend service health and runtime status | To be finalized on Day 1 |
| `POST` | `/api/datasets/upload/` | Validate and store a CSV dataset and return a bounded preview | To be finalized on Day 3 |
| `POST` | `/api/runs/start/` | Start an AutoML workflow for a selected dataset and configuration | To be finalized on Day 4 |
| `GET` | `/api/runs/{run_id}/status/` | Return run state, progress, current agent, logs, messages, and safe errors | To be finalized on Day 4 |
| `GET` | `/api/runs/{run_id}/results/` | Return dataset analysis, preprocessing summary, leaderboard, charts, and explanations | To be finalized during Days 6-10 |
| `GET` | `/api/runs/{run_id}/artifacts/` | List safe downloadable artifacts generated by a run | To be finalized during Days 9-11 |
| `POST` | `/api/models/{model_id}/predict/` | Validate JSON input and return a prediction from the saved preprocessing/model pipeline | To be finalized on Day 12 |

## Contract change process

Every finalized or changed contract must include:

1. Request fields and validation rules
2. Success response with field types
3. Error response format and relevant status codes
4. Example request and response using non-sensitive data
5. Compatibility notes for the frontend
6. Review by the other member before merge

Contract changes are made on a task branch and merged through a pull request. Breaking changes require explicit coordination before either side implements against them.
